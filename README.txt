TapTale — Professional Website Prototype

HOW TO RUN
1. Extract this ZIP.
2. Open the folder.
3. Double-click index.html.
4. Use "Create account" to enter the dashboard.

WHAT'S INCLUDED
- Professional responsive UI
- Login / account creation (demo-only localStorage)
- Add / edit / delete-style profile workflow
- Trusted family / emergency contacts
- QR code generation + download
- Public profile view
- Click-to-call contact buttons
- Mobile + desktop layouts

IMPORTANT
This is a front-end prototype, not a production backend.
Accounts, passwords and profiles are stored in the browser's localStorage.
For a real TapTale product, use a secure backend/database, hashed passwords,
real authentication, HTTPS hosting, and a public profile API/URL.
